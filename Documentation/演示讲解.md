# 用 SceneScope 展示 Unity 工程能力

演示时先打开已有 `Assets/SceneScopeDemo/Generated 2/SceneScope_Demo.unity`，在 **Tools → SceneScope → 打开诊断面板** 中操作；复制工具包到其他工程后，可以点击“生成演示场景”重新生成样本。

## 3 分钟操作

1. 扫描场景，展示问题列表、筛选、触发证据与对象聚焦。
2. 开启 Scene 热力图，选中高面数雕塑，解释“静态几何预算”与“真实 GPU 帧耗时”的区别。
3. 固定基线，筛选 SS006 小物体阴影，预览并批量关闭阴影投射。
4. 重新扫描后比较结果；按 Ctrl+Z，再扫描验证整个批次恢复。
5. 打开 HTML 报告，并展示 CI 的结构化 JSON 与退出码。

## 可以重点讲的技术

- **编辑器扩展**：UI Toolkit、虚拟化 ListView、SceneView 绘制、对象聚焦，以及 Inspector 修改后使旧诊断失效。
- **性能分析意识**：以证据和阈值提出风险；共享资源去重；扫描只读，不调用会生成材质副本的 `renderer.material`。
- **编辑器响应性**：通过 EditorApplication.update 分帧执行，6ms 为协作式预算；支持取消、退出 Play Mode 与域重载清理。单个复杂对象仍可能超出预算，这是设计边界。
- **数据与修改安全**：设置快照、同场景同阈值基线、GlobalObjectId、Undo 分组和 Prefab 实例变更记录。
- **可扩展与自动化**：ISceneRule 接口、embedded UPM 包、逐场景 CI 检查、独立离线报告及 HTML 转义。

可准确陈述的结果：本机 Unity 2022.3.62f3 完成 34 项集成检查，8 个投影修改可单次撤销；演示中的诊断从 14 条变成 6 条。没有在目标设备上测过帧率，因此不要写“FPS 提升多少”或“GPU 开销降低百分比”。
